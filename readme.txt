PENJELASAN ALUR PROGRAM

Program ini merupakan program sederhana untuk menampilkan profil dan data anggota kelompok menggunakan Python. Program menggunakan list untuk menyimpan nama bindam dan anggota kelompok, serta menggunakan perulangan while dan percabangan if-elif untuk menjalankan menu.

Program membuat list bindam yang berisi nama-nama bindam kelompok.
Program membuat list anngota_kelompok yang berisi nama-nama anggota kelompok.
Program membuat variabel profil_kelompok yang berisi deskripsi singkat mengenai profil kelompok dan logo Data Science.
Program menjalankan perulangan while True agar menu dapat ditampilkan dan digunakan secara berulang.
Program menampilkan empat pilihan menu:
Pilihan 1: Menampilkan profil kelompok.
Pilihan 2: Menampilkan daftar bindam.
Pilihan 3: Menampilkan daftar anggota kelompok.
Pilihan 4: Menambahkan anggota baru ke dalam daftar anggota kelompok.
Pengguna memasukkan pilihan menggunakan input(), kemudian nilai tersebut diubah menjadi tipe data integer menggunakan int().
Jika pengguna memilih:
1, program menampilkan isi dari profil_kelompok.
2, program menggunakan perulangan for untuk menampilkan setiap nama dalam list bindam.
3, program menggunakan perulangan for untuk menampilkan setiap nama dalam list anngota_kelompok.
4, program meminta pengguna memasukkan nama anggota baru, kemudian menambahkannya ke list menggunakan fungsi .append().
Jika pengguna memasukkan pilihan selain 1 sampai 4, program menampilkan pesan "Pilihan tidak valid" kemudian menghentikan perulangan menggunakan break.
